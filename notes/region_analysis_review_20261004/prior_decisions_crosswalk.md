## Image roles and laterality evidence

The bulk package has native high-resolution soma panels and wider context panels with traces. The four copied 5-micron datasets supply low-resolution wide fields plus full-section locators. For the other five samples, context is assembled from high-resolution native blocks; those local fields are not full-section hemisphere images. Both resolutions include marked/unmarked, trace and stack/orthogonal views where available.

The grayscale NMT/template panels under this dated review are supplementary atlas-coordinate and mask checks. They do not replace the native bulk package. The separate full-section locator gives a global hemispheric position; the wide-field trace and high-resolution soma views connect that position to the actual neuron.

Eight previously inspected native locators (one L and one R atlas-labelled neuron per copied sample) place atlas-L examples on viewer-right and atlas-R examples on viewer-left. This is recorded separately from atlas side: the native X/display convention differs from the atlas-grid X convention. The native files declare orientation unverified. Relative hemisphere placement is visible; acquisition/registration evidence remains necessary for independent absolute anatomical laterality. See `native_bulk_laterality_readback.json`.

## Reversibility and acceptance

Existing native images, canonical/staging tables and manually corrected workbooks remain unchanged. Code changes have scoped pre-edit copies and a reversible patch; new outputs stay in this dated review scope. Human annotations are retained with provenance, even where automatic reference checks conflict. No commit, push or cohort promotion is part of this review.
