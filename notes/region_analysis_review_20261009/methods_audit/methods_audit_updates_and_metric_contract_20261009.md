## Display names and formulas

| Stored identifier or measurement | Readable display | Formula and interpretation |
|---|---|---|
| Legacy regional length | Retained reconstruction length | Source index units; compartment, target-selection and registration semantics remain qualified. It is not automatically axon-only length or accepted terminal-field extent. |
| Projection_Strength | Log-scaled retained length | `log10(retained length + 1)`; the unit-dependent +1 transform must remain explicit. |
| Profile `prop` / `mean_prop` | Share of log-scaled length / mean share | Each feature's transformed length divided by the sum over selected features. Hybrid L3/L6 features overlap; this is not a raw-length budget or an exclusive anatomical partition. |
| Summary Laterality_Index | Contralateral retained length share | `Contra/(Ipsi+Contra)`: 0 ipsilateral, 1 contralateral, 0.5 equal retained totals; unavailable if the denominator is zero. Source-side uncertainty is not biological zero. Verify the older workbook's producer before applying this contract. |
| Individual Ibias | Individual ipsi/contra retained length balance | `(Contra-Ipsi)/(Contra+Ipsi)`: -1 ipsilateral, +1 contralateral, 0 equal retained totals; unavailable if the denominator is zero. For an identical denominator, this equals `2*Laterality_Index-1`. |
| Source-group LI / Projection_LI | Left vs right source contrast | `(mean_L-mean_R)/(mean_L+mean_R+epsilon)`, using neuron-level normalized profile means. Positive means a higher left-source mean. It is neither a neuron's ipsi/contra balance nor an absolute target-hemisphere preference. A value of zero when both means are zero is not bilateral innervation. |
| Novel tutorial Length_Asymmetry | Log-scaled length balance, positive ipsilateral | The tutorial actually sums Projection_Strength and computes `(Ipsi-Contra)/(Ipsi+Contra+epsilon)`. Its sign is opposite to Ibias, and it is not raw-length asymmetry. Count_Asymmetry uses target counts; Asymmetry_Score averages these two unlike measures as existing historical code. |
