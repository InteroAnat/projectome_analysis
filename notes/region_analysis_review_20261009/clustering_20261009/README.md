The saved analysis describes projection allocation in the existing 462-neuron selection; it does **not** establish insular cell types. ## Scope and method

This analysis uses the single source-bound ledger of 462 selected neurons. It includes coarse human INS evidence, atlas labels and candidates without changing any classification. It does not claim that all known or potentially insular neurons in the complete inventory are included. Exact sample/channel plus neuron filename identifies a neuron; bare numeric IDs are not unique across samples.

Whole-axon profiles use child-type-2 segment length in template millimetres. Candidate axon-end profiles use non-root type-2 leaves in the complete graph, not reviewed terminals, arbors, boutons or synapses. The two observables are fitted separately. Source ARM background does not exclude a neuron if its measured target profile is computable. Fine soma labels are preserved as metadata and do not supervise clustering.

Features are the exclusive positive, mapped labels in the actual ARM level-6 volume, with full official target names, cortical/subcortical domains and absolute target hemisphere retained. Levels 1–5 are not mixed into this feature vector. Atlas background and outside-reference measurements are retained as separate coverage covariates, not treated as anatomical targets.

For each measured nonnegative profile x, p=x/sum(x) across mapped positive targets. Primary Hellinger distance is norm(sqrt(p)-sqrt(q))/sqrt(2), followed by average linkage. This compares relative allocation and reduces domination by total reconstructed extent; it also conditions on mapped coverage and can amplify incomplete profiles. There is no target-wise z-scoring, label penalty, or invented prior cell type. A log-relative sensitivity uses log1p(1000*p), row L2 normalization and Euclidean/average linkage. The scale 1000 is an explicit sensitivity parameter, not a measured biological threshold. Endpoint presence additionally uses binary Jaccard distance with average linkage. Ward is not silently applied to arbitrary distances.

A graph without eligible candidate ends remains unassessed for endpoint analysis, with NA target counts. An eligible graph with no positive mapped target has measured zero mapped evidence but no compositional profile; its clustering assignment stays unavailable. Axon profiles likewise require positive mapped length. Both remain in the one assignment/coverage ledger with reasons and absolute totals. No missing source or endpoint measurement becomes an absent biological projection.

Candidate cuts k=2–8 are exported. For readable profile figures only, the display cut maximizes silhouette among cuts with at least five neurons in each cluster and no cluster above 90% of eligible rows; if none meets those display constraints, the fallback is explicitly marked. These size choices are display safeguards, not biological acceptance or eligibility thresholds. All requested cuts remain available, including their actual realized cluster counts, small groups and singleton limitations.

Stability reuses the validated local distance checks and average-linkage diagnostics. Each run uses 100 subsets without replacement, fraction 0.8, seed 42. Additional resampling retains 80% within each animal, then uses an equal-animal cap to expose dominant-animal sensitivity. Within-animal subsets contain 340 axon or 338 endpoint profiles, with counts per animal recorded; equal-cap subsets contain 88 profiles, 11 per animal. Actual source counts per animal, effective evaluated replicates and clusterwise Jaccard are retained. Singletons/unrepresented groups are unassessed rather than perfectly stable. Leave-one-animal-out reclusters the remaining neurons and compares their labels; it does not predict an unseen animal. Sample/channel and animal are confounded blocks in this selection. The fitted full partition remains neuron-weighted; animal-cap stability does not rebalance that fit.

Cluster profiles include neuron means and equal-contributing-animal means. Source animal, sample, hemisphere, soma ARM label and evidence composition, plus tracing/coverage covariate distributions, are descriptive checks. They are not independent-animal statistical tests. All 260 Henry coarse INS cases come from one animal; human-only fits test sensitivity to the candidate/atlas cohort but cannot establish across-animal replication. No neuron-level p-values or biological subtype claims are produced.

The historical FNT morphology-distance runs (212 or 306 neurons) remain separate and unchanged. This is a new regional projection-profile representation, not an exact-cohort FNT rebuild or a reproduction of a published terminal-arbor classifier. The local [scientific basis](../../../group_analysis/evolution_20261008/references/scientific_basis_20261009.md), [full fMOST Methods review](../../../group_analysis/evolution_20261008/references/fmost_full_methods_20261009.md) and [historical FNT validation](../../clustering_review_20261002/README.md) distinguish those methods and limits. Original SWC export origin, native-to-NMT registration acceptance and anatomical terminal review remain unresolved.
