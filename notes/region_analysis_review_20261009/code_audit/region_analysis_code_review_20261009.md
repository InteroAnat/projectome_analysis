## Preserved methods and scientific limitations

1. `neuro_tracer._mark_branch_terminals:204–219` selects **all zero-child nodes**, including dendrites/custom types and a root-only graph. `population.py:322–349` deduplicates target labels; `Terminal_Count` is a count of distinct labels, including unresolved targets, not leaf count/bouton count. A dendritic leaf in `SL_PrC` is therefore a classifier target. Changing this to strict non-root type2 leaves would be a method change, not part of these staged repairs.
2. `neuron_analysis.py:56–75` rounds each edge to .001 atlas voxels, assigns the entire edge by its proximal node, drops nonpositive/background/outside regional lengths, then retains lengths only in any region with a graph leaf. A 2-voxel A→B edge with its only leaf in B can yield **no retained regional length**; a .0004-voxel edge becomes zero. The region-wide gate does not establish that every retained edge belongs to a terminal arbor, or that excluded edges lack en passant boutons. Preserve this legacy definition and identify it in outputs; a segment-intersection/axon-only method requires a versioned derivative and sensitivity analysis.
3. `neuro_tracer.py:178–195` divides cached XYZ by250 and treats the result as atlas indices. Current export origin/reference/transform evidence remains unresolved. Gou deposited code's centre convention differs by half a voxel; that does not authorize silently changing current portal coordinates. Affine/grid agreement and a passing hemisphere mask do not validate subject registration or fine parcels.
4. `classifier.py:26–31` calls all116 labels in two CT spans “Thalamus.” Named SARM Level2 thalamus ancestry has94 labels;22 legacy-only labels belong to PreThal/EpiThal/PrT. Across nine cached workbooks, **27 neurons have41 neuron–label entries across10 such leaf labels**. Saved types are14PT/13CT; **all13CT also have true thalamic targets**, so this subset does not establish incorrect final CT assignments. See exact records and hashes in the JSON.
5. Proposed classifier policy: construct an exact named target set from SARM descendants of `SL_Thal`/`SR_Thal`, validate abbreviation–index agreement against ARM, bind the hierarchy/code hash and retain the original legacy category/type as diagnostics. Nonthalamic CT-span labels should become “unresolved category” unless a separately approved PT/other assignment exists. Preserve PT precedence initially; do not silently promote pretectum to PT. Even exact thalamic topology contains tract labels `caps`/`bsc`; synaptic target and molecular CT acceptance remain distinct questions.
6. Exact candidates and curated labels remain source-attributed. `region_labels.py` preserves anatomical digits and strips numeric portal suffixes only for explicit portal input; `getNeuronListByRegion` distinguishes SL_Pi from CL_Pi. Manual IDD5/IDM/IDV are not resolved by current ARM fine parcels. `insula_label_set.py` still describes manual labels as “resolved through CHARM” although this crosswalk is not established; correct that documentation without relabeling sources. Henry coarse INS, atlas candidates and spatial candidates remain separate evidence strata.
7. Harmonization Ia/Id→IDM and Iai→IAPM is an empirical project adaptation; Ig→IG is user policy. Neither software acceptance nor the frozen260 crosstab establishes the fine architectonic crosswalk. 114 remains provisionally IDM despite reviewed right-sided identity. The old standalone `main_scripts/region_analysis.py:185–208` additionally invents parents from sorted `First_Level` metadata and omits outside leaves (`:566–581`); deprecate or delegate it explicitly before claiming parity with the package.

Literature comparison uses the saved full-Methods notes/evidence in `group_analysis/evolution_20261008/references/`. Evrard2014 Methods pp65–66 defines histological borders with serial Nissl/Gallyas evidence, not coordinate rescue. Krockenberger2023 §2.2/§3.1 pp2022–2024 uses blinded architecture followed by tracer overlay and varicosity-bearing fibers, not leaf topology. Chikama1997 Methods pp9687–9688 charts tracer terminal fields under a different broad insular scheme. Liu2026 Discussion PDFp14 explicitly leaves long-range VEN targets unidentified. Gou2025 STAR e5–e7 separates arbor segmentation/presence from total neurite length and warns about cross-specimen arbor overlap. These sources do not validate the existing leaf gate as a biological terminal detector or PT/CT rules as molecular cell classes.
