## Measurement priorities and terminology

| Priority | Observable | Interpretation and required distinction |
|---|---|---|
| Primary | Reviewed axonal terminal-site/terminal-field evidence | Use source annotations or image review when available. Record whether an ending is verified, a reconstruction leaf, suspected truncation, or unassessed. |
| Reconstruction QC / exploratory proxy | SWC type-2 graph leaves, with node identities and coordinates | A graph leaf has no children. An axonal leaf is an endpoint of a reconstructed axon; it is not automatically a biological terminal or a synapse. Preserve excluded and unresolved compartment types. |
| Primary regional summary | Fraction of sampled neurons with reviewed target-local terminal-arbor/field evidence | Report the denominator, animal, source INS subregion, review status and coverage. Keep provisional endpoint presence separate. No observed endpoint is not proof of absent innervation. |
| Complementary terminal summary | Endpoint counts per sampled neuron and endpoint density | Keep individual leaves, multiple endings in one region, outside-atlas points and hierarchy aggregation explicit. Endpoint abundance can depend on branching and tracing completeness. |
| Exploratory terminal-field summary | Local terminal-arbor occupancy or length | Define the terminal-subtree/field rule and its spatial scale before computing it; validate it against representative source images. Do not invent a default radius or equate a dense tract with a terminal field. |
| Secondary | All-axon length, density and target occupancy | Describe reconstructed trajectories, including terminal arbors. The current all-axon measure is not a pure measure of passage-only fibers. Separating passage from terminal arbor requires an additional validated rule. |

Terminals, boutons and synapses are distinct observations. Boutons along an axon need not coincide with a graph leaf. The present seven-column SWCs do not themselves establish bouton identity, synaptic connectivity or complete reconstruction. Missing endpoint evidence must remain distinct from a verified absence.

For animal `a`, source subregion `s`, target region `r`, and `N(a,s)` eligible sampled neurons, first report both:

- Endpoint evidence frequency: `number of neurons with >=1 qualifying endpoint in r / N(a,s)`.
- Endpoint abundance: `sum of qualifying endpoint counts in r / N(a,s)`; divide by the declared target volume only when reporting volumetric density.

These quantities describe the sampled reconstructions and their declared qualification rule. Keep strict type-2-leaf proxies separate from image-reviewed terminal evidence. Publish per-neuron counts and the unassessed fraction alongside each animal summary. The candidate-map implementation conditions on neurons with at least one qualifying full-graph type-2 leaf anywhere, including outside the field of view; report that conditional denominator alongside all selected neurons. It is not the denominator for biological innervation prevalence. Reviewed arbor summaries require independently defined reviewable/target-covered denominators. Average contributing animal summaries with equal animal weights; do not replace missing animal/subregion data with zeros or count neurons as independent animals.

## Exact background and current pilot method

The background is the skull-stripped symmetric NMT template:

`atlas/NMT_v2.1_sym/NMT_v2.1_sym/NMT_v2.1_sym_SS.nii.gz`

- SHA-256: `9e37a94c4b9e5865aabb9fd3b51dcc3b2cb16f3daed39c967e68acf16cf92bee`.
- Grid: `256 x 312 x 200`, `0.25 mm` isotropic; voxel volume `0.015625 mm3`.
- The bundled NMT README describes a population T1-weighted MRI template built from 31 rhesus macaques. The symmetric template is a shared anatomical reference, not an individual projectome or MSTIM subject image. See [Jung et al., 2021](https://doi.org/10.1016/j.neuroimage.2021.117997).
- Reference hash/geometry pinning does not verify native fMOST-to-template registration or cross-species parcel correspondence.

The first pilot integrates the physical template-space length of each edge whose **child SWC type is 2**, splitting edges at voxel faces. It averages lengths across selected neurons within each animal/source subregion, divides by voxel volume for length density, then gives contributing animals equal weight. Its input convention is explicitly `atlas_index_um`: XYZ divided by the declared `250;250;250` scale gives NMT voxel indices. This is a cached-atlas coordinate convention, not proof of native acquisition calibration. No new registration, smoothing or t test is performed. Brain-mask coverage is reported; the mask does not silently remove delivered map data.

That convention remains an unaccepted assumption for anatomical interpretation. The [coordinate-origin sensitivity audit](atlas_locations/soma_audit_20261009/coordinate_origin_uncertainty_20261009.md) compares the current client, half-open center cells and the deposited Gou edge-origin convention on the same ARM6. The edge-origin alternative changes 227 of 1,912 cached-root labels without changing hemisphere. Resolve the actual portal export convention before treating either lookup as accepted; no coordinate or saved map was shifted.

The initial overview figures show `log10(1 + maximum axon-length density along depth)` on maximum-intensity MRI projections. Each background pixel therefore takes the brightest MRI intensity at any depth. This explains the unusually white, flattened appearance and loss of slice-level anatomy. Matched MRI/map slices with a shared grayscale window are the appropriate refinement for anatomical inspection. This display change does not alter map values.

The 260-neuron pilot is from **one animal**, grouped into eight declared source subregions. It is an all-axon length demonstration; it contains no terminal detector. The user-selected IDM label for 251637/114 remains provisional. See [saved run provenance](projection_maps/curated_reference/run_provenance.json) and [independent full-map readback](projection_maps/curated_reference_review/projection_run_readback.json).

New [matched-slice figures and display provenance](projection_maps/curated_reference_matched_slices_20261008/matched_slices_provenance.json) use the same MRI and map plane in every panel, with a fixed brain-intensity percentile window. Cuts maximize summed map density separately for each axis/map and are explicitly labelled; they are display selections, not evidence of full target coverage. Original maps and MIP figures are preserved.

The independent [source-leaf census](validation/terminal_leaf_source_audit_20261008.json) finds 38,795 full-graph leaves in these 260 SWCs: 27,020 type 2, 10,857 type 3, 909 type 0 and nine type 10. Thirty-three neurons have no type-2 nodes, and 39 contain unresolved type-0/10 leaves. Their biological compartment meanings require clarification. The legacy `Terminal_Count` counts distinct target regions from all-compartment leaves rather than axonal endings. Its values must not be relabelled as terminal counts. The Known/Unknown reporting defect is now corrected with focused regressions: two `Out_of_Bounds` target entries move from Known to Unresolved in the frozen 562-neuron report, without changing any graph, class or cohort. See [reporting readback](validation/terminal_reporting_20261009/comparison_summary.json), the historical [terminal measurement plan](references/terminal_site_measurement_plan_20261008.md), and the new [full Methods review](references/scientific_basis_20261009.md).
