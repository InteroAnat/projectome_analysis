The generation rule in `01_build_insula_coord_reference.py` groups the saved manually labelled 251637 somata by subregion, pools hemispheres, folds X as `abs(Soma_NII_X - 128)`, and leaves Y/Z unchanged. Bounds use NumPy quantiles 0.005 and 0.995 separately for each axis; this is an axis-wise 99% interval, not a claim that the box contains 99% of the joint anatomical distribution. Subregions with fewer than two source neurons are omitted. The saved folded reference contains 260 somata over five subregions. Recomputing its quantiles from saved reference-neuron coordinates differed by at most 1.4211e-14 NII units. Current readback of `neuron_tables_new/251637_INS_HE_inferred.xlsx` matches all 260 reference neuron IDs, original region strings and coordinates exactly; this current comparison does not invent a historical generation receipt. Both source hashes are recorded.

Discovery now requires `--bbox-csv` and `--geometry-mode folded-mm|raw-legacy`. Folded mode requires explicit `Soma_NII_X_folded`, midline 128 and voxel scale 0.25 mm metadata. It converts folded X and Y/Z bounds and coordinates to physical millimetres, then applies inclusive 2 mm padding by default. This equals eight NII voxels on each bound. Raw legacy mode deliberately declares raw X, rejects folded frame metadata, validates finite ordered bounds and any scale/midline metadata, and defaults to zero padding. An unframed historical raw table is allowed only through that explicit legacy mode. There is no automatic frame guess or alternate-file fallback.
