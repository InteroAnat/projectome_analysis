# Multi-monkey maps: readable matched-slice figures

[Plain-language map terminology](../../../../docs/region_analysis_terminology.md). A candidate axon end is a non-root axon-labelled graph leaf, not a verified biological terminal. Endpoint-eligible neurons have at least one such leaf anywhere, including outside the reference field of view. Within each animal/source group, density is per eligible neuron (endpoints) or per selected neuron (axon length), and per reference mm³. Across animals, each contributing animal map has equal weight. Occupancy is the fraction of eligible neurons with at least one candidate end in a voxel, counting each neuron once.

436 unique neurons across eight established animals. HumanINS, AtlasINS, Candidate and G_exploratory remain separate, each split by source hemisphere. These are unsmoothed descriptive maps; graph endpoints are not verified biological terminals. The background is the pinned skull-stripped symmetric **population T1-weighted NMT v2.1 MRI**, not individual fluorescence. Every panel uses the same MRI and map plane. Common XYZ voxel cuts are **56, 200, 87**, corresponding to approximately X −17.875, Y 22.25 and Z 13.75 mm. They were selected from the main endpoint-occupancy profile and fixed for all families and previews. The sagittal cut is left-sided; source hemispheres are not mirrored. These cuts are display selections, not a census of all projections.

MRI grayscale uses brain-mask intensity percentiles 1–99.5. Density uses `log10(1 + density)` with a shared 99.5th-percentile upper color limit within each family. Occupancy uses linear 0–1. Between families/runs, color limits can differ: use physical map values and sidecar limits for quantitative comparisons. Maps are not smoothed, clipped or changed by rendering. T1 white matter can remain bright on true slices; there is no depth maximum in these sheets.

Endpoint maps use 403 computable / 436 selected neurons; 33 lack eligible type-2 leaves and remain unassessed. Axon maps average over all selected neurons, preserving the source-compartment limitation. Each row records its selected/computable counts, or contributing animals. Animal means give equal weight to contributing animals and do not fill absent strata with zeros. HumanINS has one contributing animal; it does not supply replicated human-confirmed INS inference.

Every family has `matched_slices_provenance.json` recording cuts, map/background/reviewer/code hashes, color limits, PNG hashes and successful title-overlap checks. The [wording-variant receipt](../../../../notes/region_analysis_review_20261009/readable_figures_receipt.json) verifies all 33 main-plus-preview sheets and preserves original map/figure hashes. MRI planes, cuts and display limits match the previous layout. Original [layout-v2](../multimonkey_coarse_20261009_layout-v2/README.md) figures remain available. These 25 sheets and eight separate previews improve the visible measurement names without recomputing scientific maps.
