Read the [coordinate-origin uncertainty addendum](coordinate_origin_uncertainty_20261009.md) before interpreting parcel assignments. The initial parent-directory audit and intermediate `verified_root_consensus` child are retained as dated computational evidence; the validated child corrects the ambiguous portal token `CL_208` interpretation. Here `CL` is an anatomical abbreviation with a numeric portal region suffix, not a left-hemisphere prefix. The initial audit also compared four alternate-path copies against the reviewed original-path byte hash; that inappropriate cross-path comparison is corrected by path-specific binding in the validated output. No source file changed.

The audit covers all **8,746 exact neuron identities from 47 live macaque sample IDs**. No channel variants, absent historical aliases, or neuron IDs were merged. It read and hashed **2,480 documented atlas SWC files** covering **1,912 distinct exact live identities** in ten samples. All files had one valid root; **6,834 identities have no local atlas SWC and remain unassessed by this channel**. One primary-cache identity absent from the live inventory was explicitly excluded. The separate `251637_b` cache was not mapped to `251637`; native `swc_raw`/`raw_swcs` and mirrored SWCs were excluded.

Sources are the declared ION atlas cache `neuron-vis/resource/swc` (1,483 eligible files), `main_scripts/processed_neurons/251637` (562), the Oct 4 identity/hash-bound recovered atlas cache (127), the unmirrored `group_analysis/fnt/nmt_swcs` source cache (306), and the exact reviewed `atlas_112.swc`/`atlas_114.swc` copies (2). All 2,480 source hashes were freshly verified before reusing the initial fresh full-file root read records. Representative independent NumPy full-graph reads checked **28 sources**, including both reviewed neurons and every represented sample/cache stratum, plus background/boundary coverage. No historical per-neuron result was accepted without exact current path/hash validation. Among prior path-specific hash-bound records, 1,612 matched and none changed; 868 had no prior path-specific bound hash.

There are **306 identities with distinct source byte hashes**. Every source root and direct atlas lookup agrees exactly within each identity. These receive explicit root-consensus status; whole-graph equivalence and selection of an authoritative graph remain unadjudicated. The other 1,606 covered identities have one distinct byte source. The discrepancy table retains these source differences instead of silently choosing one copy.

## Coordinates and references

The existing monkey tracer and cached-source provenance declare **SWC XYZ / 250 = NMT voxel indices**. Portal `getSoma` values use the same declared physical-index micrometre encoding. The inventory's `nmt_*_mm` columns are index-scaled millimetres, not affine world coordinates. The audit does not inverse-apply the NIfTI affine to these encoded values.

The bundled NMT v2.1 symmetric reference has shape `(256,312,200)`, 0.25 mm diagonal affine with translation `(-31.875,-27.75,-8)`, and template SHA256 `9e37a94c4b9e5865aabb9fd3b51dcc3b2cb16f3daed39c967e68acf16cf92bee`. The direct lookup uses the ARM level-6 volume `[...,0,5]` and ARM key hierarchy. Exact reference, atlas, mask, key, input and code hashes are in [provenance.json](validated_atlas_lookup/provenance.json). ARM and official LR masks share the exact reference grid. Mask values are **1=R, 2=L, 0=Unknown**, checked against all side-coded ARM voxels: 1,891,157 agreeing voxels per side and zero opposite-side voxels.

Lookup follows the existing NumPy nearest-index/ties-to-even rule, including rounded bounds; **eight covered roots lie exactly on a half-voxel boundary**. Root coordinates are preserved at full stored precision. All 1,912 covered roots are within the official brain mask, including 295 with ARM label `Unknown_0`; an ARM background label does not imply that the root lies outside the brain mask.

## Separate evidence channels

Every covered identity also has portal soma coordinates. The maximum cached-root versus portal-coordinate distance is **0.0889144 micrometres**; none exceeds the explicit 1 micrometre mismatch threshold. The two direct ARM6 lookups agree for all 1,912 covered identities. This establishes consistency of these stored coordinate channels with this local lookup; it does not establish how the server generated its supplied region labels.

Portal-coordinate-only lookup covers **8,409 identities**, with **337 missing coordinates** retained as missing. There are 1,388 missing portal region metadata values and no explicit portal `Unknown` sentinel labels in this snapshot. Direct ARM6 lookup produces 295 background labels among covered cached roots and 1,032 among portal-coordinate lookups. Missing metadata, background lookup, source absence and candidate status are distinct fields.

The inherited inventory's insula/G/folded-box candidates remain unchanged. Cached sources cover 309/310 portal-label insula candidates, 32/32 G candidates, 441/500 strict insula-or-folded-box candidates, and 465/524 insula-or-G-or-folded-box candidates. The one portal-label insula candidate without an own cached SWC is `233001ch2/qroot146.swc`. The [independent candidate readback](validated_atlas_lookup/independent_full_readback_candidates.csv) explicitly distinguishes the shared insula label set from the narrower ARM `Ins` hierarchy branch: direct cached-root label-set candidates number 309, portal-coordinate label-set candidates 310, and hierarchy-branch-only candidates 161 in each channel. These remain candidate classifications rather than accepted anatomical membership.

There are **261 normalized textual differences** between portal-supplied labels and direct cached-root labels, and 1,438 between supplied labels and all portal-coordinate lookups. These are descriptive vocabulary/granularity findings, not portal bugs. A separate [token readback](validated_atlas_lookup/label_vocabulary_readback.json) identifies 94 of the 261 covered differences as the same anatomical token after explicitly dropping the subcortical side prefix. The remaining 167 include portal `HI` versus direct `DGA`/`CAA`, and portal `S` versus direct `SA`; their server assignment lineage remains unresolved. No direct ARM-label/mask conflict, portal-supplied explicit-side conflict, or reviewed-side conflict remains after correct portal-prefix parsing.

All **296 original Henry annotation rows for 295 distinct neurons** are retained, including the duplicate rows for 114. The exact hash-bound reviewed JSON supplies **112 R-IDM/layer 3** and **114 provisional R-IDM/layer 3**. Both source roots have mask side R and direct ARM6 label `Unknown_0`. The reviewed parcel decisions and original labels remain separate from direct atlas lookup; no manual label is replaced and 114's provisional status is preserved.

## Validation and limits

Seven focused unit tests pass for encoded-index versus affine-world semantics, half-voxel/bounds behavior, LR masks, missing sources/coordinates, root parsing, byte-source/root collisions, exact reviewed identity/hash binding and the portal anatomical `CL` ambiguity. Independent persisted readback verifies all 8,746 exact identities, all 47 saved raw soma snapshot hashes, the 337 missing-coordinate denominator, representative fresh roots/atlas lookup, and all original/reviewed manual rows.

The registration direction **raw fMOST brain and neurons to NMT is user described**. Original transforms, source atlas/reference versions used by the server, landmark acceptance, and the portal label-generation algorithm remain unverified. Coordinate/root agreement is software and spatial evidence, not scientific registration acceptance. No endpoints, projection maps, native transforms, network downloads, canonical workbook edits, or anatomical promotions were produced by this audit.
